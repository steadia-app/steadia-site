Steadia — Support

Questions, bugs, and the things that trip people up

Email steadia.app@gmail.com. Include your iOS version and what you were doing when it happened — there is no crash reporting in the app, so your description is all there is to go on.

Common issues

The rest alert doesn't fire when my phone is locked

Almost always notification permission. Check Settings → Notifications → Steadia → Allow Notifications.

iOS only asks once. If the prompt was declined or dismissed the first time, the app cannot ask again, and the failure is silent — the timer still counts down and the in-app alert still sounds, so only the locked-screen case is affected. Turning permission back on in Settings fixes it immediately.

The countdown on my lock screen shows 1:—— instead of a time

Live Activities need their own permission the first time. Tap Allow on the "Allow Live Activities from Steadia?" prompt, or enable it in Settings → Steadia → Live Activities.

I can't hear the alert

The rest alert is designed to sound through the ring/silent switch, and to duck your music rather than stop it. If you hear nothing at all, check the volume while the app is open — the app's audio follows the media volume, not the ringer.

Will I lose my history if I delete the app?

Yes. Everything is stored on your device and nowhere else. There is no account to restore from. Use More → Data → Export file before deleting or switching phones.

Moving to a new iPhone

Two ways, both under More → Data:

  • Export file on the old phone, then Import file on the new one. Works for a history of any size.
  • Copy sync code on the old phone and paste it on the new one. No file needed, but very large histories are too long to paste — the app will tell you and point you at the file instead.

Can I change the program?

Yes — the Program tab has several built-in splits, and you can copy any of them and edit the exercises, sets and rep ranges, or build one from scratch.

What the app deliberately does not do

  • No account, no sign-in, no cloud sync
  • No ads, no tracking, no analytics
  • No subscription
  • No Apple Health integration
  • No internet connection — it works the same in a basement gym as anywhere else

See the privacy policy for the detail.
